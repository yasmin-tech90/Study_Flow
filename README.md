# StudyFlow 📚

StudyFlow is a personal learning tracker designed to help students study smarter and stay consistent.

The app combines spaced repetition, daily review tracking, progress statistics, and coding practice tracking in one simple and organized platform.

## ✨ Features

- 📚 Add and manage study subjects
- 🔄 Automatically generate spaced repetition schedules
- 📅 View all scheduled reviews
- ⭐ See reviews that are due today
- ✅ Mark reviews as completed
- 📊 Track monthly reviews and completion rate
- 🔥 Monitor learning progress and streaks
- 💻 Track solved coding problems
- 🔍 Search and filter coding problems
- 💾 Save all user data using LocalStorage

StudyFlow focuses on turning study plans into a consistent daily learning workflow—helping students stay organized, track their progress, and build better study habits.
